# pureo — ROADMAP

> **이 문서가 마일스톤·태스크 진행의 SSOT다.** 체크박스로 진척을 추적한다.

**원칙**: 각 마일스톤이 끝날 때마다 배포 가능한 상태를 유지한다.

> 2026-07-23 재편: 포트폴리오 건강검진 중심으로 방향 전환. M1은 그대로 완료하고,
> M2 이후를 진단 중심으로 재정의했다. 이전 M2~M4(관심종목·국내 시세·미니 포트폴리오)의
> 미착수 항목은 백로그로 이동.

**학습 포인트**: `useQuery`, SSR prefetch(`HydrationBoundary`), 데이터 성격별 캐싱 전략

- [x] M1-01 Next.js 수동 셋업 + FSD 골격 + Vitest
- [x] M1-02 외부 API 스파이크 (Finnhub·Twelve Data 응답 필드 검증)
- [x] M1-03 도메인 타입 + PER/PBR 해석 룰 (TDD)
- [x] M1-04 가격 흐름 해석 + 회사 소개 문장 + 용어 사전 (TDD)

- [x] M1-09 종목 카드 페이지 (SSR prefetch + 4개 섹션 + 부분 에러 UI)

## M3 — 진단 입력 + 리포트 화면

**목표**: 종목+비중을 입력하면 리포트를 보여준다 (무저장 — 새로고침 시 소멸 허용).
**학습 포인트**: `useMutation` + 성공 라우팅, 다단계 폼 상태, 통합 검색 전환

- [ ] M3-01 통합 검색을 메타데이터 기반으로 전환 (국내+미국, 미지원 종목 안내)
- [ ] M3-02 진단 입력 위저드 (종목 추가/삭제 + 비중 입력 + 현금 + 합계 100% 검증)
- [ ] M3-03 선택 설문 3문항 (투자 기간·목적·손실 허용)
- [ ] M3-04 `POST /api/diagnose` (Zod 검증 → 룰 엔진 → 결과 반환) + 통합 테스트
- [ ] M3-05 리포트 화면 (건강점수·노출 차트·유형·시나리오·코멘트 + 종목 카드 링크)
- [ ] M3-06 홈을 랜딩 + 진단 시작으로 재편 (기존 검색은 보조 배치)

**완료 기준**

- [ ] 프로덕션 URL에서 입력 → 진단 → 리포트 전체 플로우 동작
- [ ] 비중 합계 검증이 클라이언트·서버 양쪽에서 동작
- [ ] 리포트에서 종목 클릭 → 기존 해석 카드 진입
