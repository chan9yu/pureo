# pureo — PRD

> **이 문서가 제품 요구사항의 SSOT다.** 설계 변경 시 이 문서와 `ROADMAP.md`를 갱신한다.

## 1. 문제

증권사 앱은 숫자(PER·PBR·시가총액)를 **보여줄 뿐, 해석해주지 않는다.**
주식 초보자는 "그래서 이게 비싼 거야 싼 거야?"에 답을 얻지 못하고, 증권 앱을 여는 것 자체를 어려워한다.

## 2. 타깃 사용자

- 본인 + 증권 앱을 어려워하는 지인 소수
- 국내·미국 주식에 관심은 있지만 재무 지표를 읽을 줄 모르는 초보자

## 3. 차별화

**숫자를 '보여주는' 앱이 아니라 '풀어 읽어주는' 앱.**
거래 기능이 없는 것이 정체성 — 증권 앱을 열기 전에 먼저 여는 앱. 모든 지표는 쉬운 한국어 문장과
시각 요소(게이지·스파크라인)로 해석되고, 전문 용어에는 쉬운 말 설명이 붙는다.

## 4. 핵심 기능

| #   | 기능              | 설명                                                                            |
| --- | ----------------- | ------------------------------------------------------------------------------- |
| 1   | 종목 검색         | 티커/회사명 자동완성 (국내·미국)                                                |
| 2   | 종목 해석 카드    | 회사 소개 한 문장, 가격 흐름 문장 해석, PER·PBR 게이지, 용어 풀이, 디스클레이머 |
| 3   | 관심종목 대시보드 | 하트로 등록한 종목 카드 그리드 + "내가 이해한 것" 메모                          |
| 4   | 미니 포트폴리오   | 보유 종목 수동 입력 → 환율 반영 합산 + 쉬운 말 진단                             |
| 5   | 로그인            | Google OAuth 하나                                                               |

## 5. 비목표 (Non-Goals)

- 실거래 연동, 실시간 호가·차트
- 뉴스 수집/요약, 알림 푸시, 커뮤니티
- E2E 테스트, 다크모드 (필요해지면 재검토)

## 6. 성공 기준

- 본인이 종목을 살펴볼 때 증권 앱보다 pureo를 먼저 여는가
- 주식을 어려워하는 지인이 설명 없이 카드를 읽고 이해하는가
- 모든 마일스톤이 끝날 때마다 배포 가능한 상태를 유지하는가
- 학습 목표 달성: Next.js App Router(RSC·Route Handler·SSR prefetch)와 TanStack Query v5
  (query·mutation·invalidation·낙관적 업데이트·폴링)를 실전 코드로 경험

## 7. 기술 결정 요약

- **스택**: Next.js (App Router) + TypeScript strict, TanStack Query v5, Tailwind CSS 4,
  Vitest + MSW, pnpm 11 / Node 24, Vercel 배포
- **아키텍처**: FSD v2.1 미니멀(`app`·`pages`·`shared`) — 규칙은 `.claude/rules/project-structure.md`
- **데이터 원칙**: 외부 API는 Route Handler로 프록시(키 은닉 + 서버 캐시), 시세·지표는 DB에
  저장하지 않음. DB(M2+, Neon + Drizzle)에는 사용자가 만든 데이터만
- **해석 룰**: 순수 함수(규칙 기반) — 이후 LLM 해석으로 교체 가능한 인터페이스
- **외부 데이터**: 미국 Finnhub + Twelve Data, 국내 공공데이터포털 + DART, 환율 한국수출입은행
  (모두 무료 티어, provider 인터페이스로 추상화)
