# pureo

어려운 주식 숫자를 쉬운 말로 풀어 읽어주는 종목 카드 앱.

증권사 앱은 PER·PBR·시가총액을 보여줄 뿐, 해석해주지 않는다.
<br />
pureo는 모든 지표를 쉬운 한국어 문장과 시각 요소(게이지·스파크라인)로 풀어 읽어준다.
<br />
거래 기능이 없는 것이 정체성 — 증권 앱을 열기 전에 먼저 여는 앱.

> 현재 초기 개발 단계로, [ROADMAP](docs/ROADMAP.md)의 M1(미국 종목 검색 + 해석 카드)을 진행 중이다.

## 주요 기능

- **종목 검색** — 티커/회사명 자동완성 (국내·미국)
- **종목 해석 카드** — 회사 소개 한 문장, 가격 흐름 해석, PER·PBR 게이지, 용어 풀이
- **관심종목 대시보드** — 하트로 등록한 종목 카드 그리드 + "내가 이해한 것" 메모
- **미니 포트폴리오** — 보유 종목 수동 입력, 환율 반영 합산과 쉬운 말 진단

## 시작하기

Node 24.x와 pnpm 11.x가 필요하다 (`.nvmrc` 참고).

```bash
pnpm install   # git hooks(lefthook) 자동 설치
pnpm dev       # http://localhost:3300
```

### 스크립트

| 명령              | 설명                  |
| ----------------- | --------------------- |
| `pnpm dev`        | 개발 서버 (포트 3300) |
| `pnpm build`      | 프로덕션 빌드         |
| `pnpm start`      | 프로덕션 서버 실행    |
| `pnpm lint`       | ESLint 검사           |
| `pnpm format`     | Prettier 포맷팅       |
| `pnpm type:check` | TypeScript 타입 검사  |

## 설계 원칙

- **외부 API는 Route Handler로 프록시** — API 키 은닉과 서버 캐시. 시세·지표는 DB에 저장하지 않고 DB에는 사용자가 만든 데이터만 담는다.
- **해석 룰은 순수 함수** — 규칙 기반으로 시작하되, 이후 LLM 해석으로 교체 가능한 인터페이스를 유지한다.
- **FSD v2.1 미니멀 아키텍처** — `app` · `pages` · `shared` 레이어, 단방향 의존.
- **마일스톤 단위 배포** — 각 마일스톤이 끝날 때마다 배포 가능한 상태를 유지한다.

외부 데이터: Finnhub, Twelve Data (미국) · 공공데이터포털, DART (국내) · 한국수출입은행 (환율)
