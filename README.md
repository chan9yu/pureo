# pureo

내 포트폴리오의 구조를 쉬운 말로 진단해주는 앱.

증권사 앱은 수익률 숫자를 보여줄 뿐, 포트폴리오가 구조적으로 건강한지 해석해주지 않는다.
<br />
pureo는 종목과 비중만 입력하면 편중·집중·레버리지 같은 구조적 위험을 쉬운 한국어 문장과 시각 요소로 풀어 읽어준다.
<br />
거래 기능이 없는 것이 정체성 — 종목 추천 없이 분산 관점만 제시하는 앱.

> 현재 초기 개발 단계로, [ROADMAP](docs/ROADMAP.md)의 M1(미국 종목 검색 + 해석 카드)을 진행 중이다.

## 주요 기능

- **진단 입력** — 종목 검색 자동완성(국내·미국) + 비중 % 입력 + 선택 설문
- **진단 리포트** — 건강점수, 국가·섹터·테마·통화 노출, 집중도, 포트폴리오 유형, 시나리오 영향도
- **공유 링크** — 리포트마다 공유 URL, 종목명 기본 비공개 + "나도 검사받기"
- **종목 해석 카드** — 회사 소개 한 문장, 가격 흐름 해석, PER·PBR 게이지, 용어 풀이

## 시작하기

Node 24.x와 pnpm 11.x가 필요하다 (`.nvmrc` 참고).

```bash
pnpm install   # git hooks(lefthook) 자동 설치
cp .env.example .env.local   # API 키 입력
pnpm dev       # http://localhost:3300
```

### 환경 변수

| 변수                 | 용도                       | 발급처                        |
| -------------------- | -------------------------- | ----------------------------- |
| `FINNHUB_API_KEY`    | 미국 종목 검색·프로필·지표 | https://finnhub.io (무료)     |
| `TWELVEDATA_API_KEY` | 미국 가격 시계열           | https://twelvedata.com (무료) |

## 설계 원칙

- **외부 API는 Route Handler로 프록시** — API 키 은닉과 서버 캐시. 시세·지표는 DB에 저장하지 않고 DB에는 사용자가 만든 데이터(리포트 스냅샷)만 담는다.
- **진단·해석 룰은 순수 함수** — 규칙 기반으로 시작하되, 이후 LLM 해석으로 교체 가능한 인터페이스를 유지한다.
- **시세 없는 진단** — 진단은 비중 기반이라 가격 데이터가 필요 없다. 종목 메타데이터(섹터·테마·ETF 여부)는 git으로 관리하는 정적 큐레이션 모듈.
- **FSD v2.1 미니멀 아키텍처** — `app` · `pages` · `shared` 레이어, 단방향 의존.
- **마일스톤 단위 배포** — 각 마일스톤이 끝날 때마다 배포 가능한 상태를 유지한다.

외부 데이터(종목 해석 카드 전용): Finnhub, Twelve Data (미국) · 한국수출입은행 (환율)
